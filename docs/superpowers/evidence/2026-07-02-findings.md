### Query A1: Status Distribution + No-op Detection

```sql
SELECT
  status,
  COUNT(*) AS n,
  COUNT(*) FILTER (WHERE provider_message_id LIKE 'noop-%') AS noop_marked_sent,
  MAX(created_at) AS latest
FROM notification_jobs
GROUP BY status
ORDER BY status;
```

**Purpose:** Detect if jobs are SENT with no-op ids (Cause #1) or PENDING/DEAD (Cause #2/3/4).

**Expected result format:**
```
status | n | noop_marked_sent | latest
```
